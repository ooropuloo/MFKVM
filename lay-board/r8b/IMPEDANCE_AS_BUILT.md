# r8b 阻抗線：設計值和板廠生產值

2026-11-16 下單。板廠工程審核時，為了在指定疊構（JLC06121H-3313）上達到阻抗目標，把差動線的線寬和間距調整如下。疊構沒有變，中心距沒有變。

**實體板照「生產值」做，和 `fab_r8b/` 的 Gerber、`kicad/` 的板檔不同。** 這個 repo 裡沒有板廠改完的生產檔。

## 調整內容

銅厚 1 oz，公差 ±10 %。

| 層 | 類型 | 目標 | 參考層 | 設計值（線寬／間距） | 生產值（線寬／間距） |
|---|---|---|---|---|---|
| L1 | 外層差動 | 100 Ω | L2 | 5.0 / 7.8 mil（0.127 / 0.198 mm） | **4.7 / 8.1 mil**（0.119 / 0.206 mm） |
| L6 | 外層差動 | 100 Ω | L5 | 5.0 / 7.8 mil（0.127 / 0.198 mm） | **4.7 / 8.1 mil**（0.119 / 0.206 mm） |
| L6 | 外層差動 | 90 Ω | L5 | 7.09 / 9.6 mil（0.180 / 0.244 mm） | **6.37 / 10.32 mil**（0.162 / 0.262 mm） |

100 Ω 是 HDMI TMDS 和 MIPI CSI，90 Ω 是 USB 2.0。每一列的線寬加間距在調整前後相同，所以是把線改細、中心線不動。

## 和設計時的阻抗表對照

設計時列了六列受控線（`fab_r8b/JLC_impedance_table.csv`），板廠調整了其中三列：

| 設計時列的 | 板廠有沒有調整 | 說明 |
|---|---|---|
| L1、L6 100 Ω 差動 0.127 / 0.198 mm | 有 | TMDS、CSI |
| L6 90 Ω 差動 0.18 / 0.32 mm | 有，但取的間距是 0.244 mm | 見下一節 |
| L1 90 Ω 差動 0.18 / 0.32 mm | 沒有列 | USB 在 L1 只有約 2.35 mm |
| L1、L6 50 Ω 單端共面 0.15 mm | 沒有列 | LNA_OUT 每面約 0.5 mm，太短 |

## USB 的間距為什麼是 9.6 mil

板上 USB_DP／USB_DN 的間距不是單一值（照 `tools/pairgap.py` 的方法從板檔量出）：

| 層 | 間距 | 長度 |
|---|---|---|
| L6 | 0.24 mm（約 9.6 mil） | 約 1.0 mm |
| L6 | 0.32 mm（12.6 mil） | 約 4.1 mm |
| L6 | 0.82 mm（扇出） | 約 0.7 mm |
| L1 | 0.32 mm | 約 1.3 mm |
| L1 | 0.82 mm（扇出） | 約 1.05 mm |

板廠取的是 0.24 mm 那一段。線寬改成 6.37 mil 之後，主線段的間距約 0.338 mm（13.3 mil），不是表上的 10.32 mil。

## 用本專案的場解算器代回去算

`tools/r6/s3_solver.py`，含防焊，h 0.0994 mm、εr 4.1、銅厚 0.035 mm。只是模型，沒有量測。

| 位置 | 線寬 / 間距 mm | 設計值 Ω | 生產值 Ω | 允許範圍 |
|---|---|---|---|---|
| TMDS、CSI 主線段 | 0.127 / 0.198 → 0.119 / 0.206 | 99.1 | 102.2 | 90–110 |
| TMDS 過 ESD 那段（中心距 0.500） | 0.127 / 0.373 → 0.119 / 0.381 | 105.9 | 108.9 | 90–110 |
| USB 主線段（中心距 0.500） | 0.180 / 0.320 → 0.162 / 0.338 | 89.1 | 94.2 | 81–99 |
| USB 窄段 | 0.180 / 0.244 → 0.162 / 0.262 | 86.9 | 92.2 | 81–99 |
| USB 扇出，幾乎不耦合（中心距 1.0） | 0.162 / 0.838 | — | 97.7 | 81–99 |

全部在 ±10 % 內。餘裕最小的是 TMDS 過 ESD 那段，離上限 1.1 Ω，長約 2.8 mm。板廠的模型比這裡的解算器低約 3 Ω：這裡算 5.0 / 7.8 mil 是 99.1 Ω，板廠認為要改細才到 100 Ω。

## 還不知道的事

- 板廠是只改了阻抗表指到的走線，還是把同一層所有 0.127 mm 的線都改細。0.127 mm 也用在一般訊號線。
- L1 的 USB 段和 LNA_OUT 有沒有被動到。
- 實際做出來的阻抗。
